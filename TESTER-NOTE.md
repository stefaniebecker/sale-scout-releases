# Trying out Sale Scout

Thank you for testing this!

Kelly Stumpe (The Car Mom) and I built this together — she's been using it daily
and now we want to know whether it works for someone who isn't us.

**What it is:** Sale Scout emails you every morning with which products in your
Amazon storefront have gone on sale — with links ready to post. So instead of
checking prices by hand, you open your inbox and know what to post that day.

It also tells you when big retailers like Anthropologie or Target are running a
real sale, in case that's worth covering too.

---

## What you'll need

**The Claude Code app** on a Mac or PC — the one that works with files on your
computer, not the website. Free to download at **claude.ai/download**. You'll
need a paid Claude plan to use it.

**Amazon API access.** This is a free application inside your Amazon Associates
account, but **Amazon approves it by hand and it can take a few days.** It's the
one step that isn't instant, so it's the first thing you'll do. Everything else
gets set up while you wait.

**A computer that's on in the morning.** Sale Scout runs on your own machine, so
it can't check prices while your laptop is closed. If yours is usually asleep,
you can just ask Claude to run it whenever you sit down instead.

---

## How to start

**1.** Unzip the file I sent you.

**2.** Open the **Claude Code** app.

**3.** Type this:

> Please install the Sale Scout skill. The file is in my Downloads folder.

**4.** Then type:

> Set up Sale Scout

Claude takes it from there and does the rest for you. **You should never have to
type a command.** If something ever looks like computer code, just say *"can you
do that for me?"*

---

## What to expect

So nothing feels broken:

- **Claude installs a few things first.** One is a big download and can take
  several minutes of looking like nothing is happening. That's normal.
- You may get a Mac pop-up about "command line developer tools" — click
  **Install** and wait.
- **Then you'll apply to Amazon**, and wait a few days for them.
- **Each scan takes about 3–5 minutes** once you're running. Also normal.

Actual hands-on time is about 20 minutes, spread around the Amazon wait.
